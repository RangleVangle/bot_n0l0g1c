🤖 AI Trading Bot – распределённая торговая система на базе LLM и RL
Добро пожаловать в проект AI Trading Bot – мощной, самообучающейся системы для автоматической торговли криптовалютными фьючерсами на бирже Bybit.
Бот использует ансамбль из шести AI‑агентов, работает на 4× RTX 3090 и способен анализировать рынок как профессиональный трейдер.

🚀 Возможности
6 специализированных агентов:

Technical Analyst – анализирует технические индикаторы (RSI, MACD, объём) с помощью большой языковой модели (LLM).

Sentiment Analyst – оценивает рыночный сентимент на основе цены и волатильности (LLM).

Risk Manager – оценивает риск сделки с учётом баланса, просадки и волатильности (LLM).

RL Master – агент на основе обучения с подкреплением (PPO), принимает решения, опираясь на исторические данные.

Triangle Scanner – детектор треугольных паттернов (алгоритмический).

Retest Scanner – детектор ретестов уровней поддержки/сопротивления (алгоритмический).

Распределённая архитектура – каждый агент работает в отдельном процессе (воркере). Тяжёлые LLM-агенты используют vLLM на 4 GPU, лёгкие детекторы – на CPU.

RabbitMQ – координация между основным ботом и воркерами: задачи отправляются асинхронно, результаты возвращаются.

Redis – кэширование общих данных (цены, баланс) и быстрый обмен состоянием.

Самообучение – каждая сделка сохраняется в SQLite (trading_memory.db). RL‑агент периодически дообучается на накопленном опыте, веса агентов адаптируются по результатам.

Продвинутое логирование – сквозной идентификатор (correlation_id) для отслеживания пути каждого запроса, логи в JSON с ротацией, отдельный лог сделок.

Уведомления (опционально) – Telegram‑алерты о критических событиях (падение воркера, большая просадка, ошибки API).

Макро‑данные – бот может получать реальные данные с CoinMarketCap (доминирование BTC, индекс страха и жадности) для улучшения качества решений.

🏗️ Архитектура системы




















Как это работает по шагам:

Основной бот сканирует топ‑15 монет по объёму, загружает свежие свечи и публикует задачи для каждого агента в соответствующие очереди RabbitMQ (например, technical_queue, sentiment_queue).

Воркеры на риге подписаны на свои очереди. Получив задачу, они:

для LLM-агентов – отправляют запрос к vLLM (сервер на тех же GPU) с промптом, содержащим индикаторы и рыночный контекст;

для детекторов – выполняют быстрые алгоритмические расчёты.

Результаты (JSON с полями signal, confidence, reasoning) возвращаются в RabbitMQ и попадают к оркестратору.

Оркестратор (AITradingOrchestrator) собирает все ответы, вычисляет взвешенный консенсус и возвращает итоговый сигнал боту.

Бот принимает торговое решение:

если сигнал достаточно сильный (консенсус > 0.3 или < -0.3) – открывает позицию (лонг или шорт) с заданным TP/SL;

обновляет внутреннее состояние, сохраняет сделку в trading_memory.db.

Периодически (раз в сутки) запускается дообучение RL‑агента на новых данных, а веса агентов пересчитываются на основе их эффективности.

🖥️ Требования к железу
Минимальные: 4× NVIDIA RTX 3090 (24 ГБ каждая), 32+ ГБ RAM, SSD объёмом от 500 ГБ.

Рекомендуемые: NVMe SSD на 1–2 ТБ, второй аналогичный риг для масштабирования.

ОС: Ubuntu 22.04 / 24.04 (или любой Linux с поддержкой Docker и NVIDIA драйверов).

⚙️ Быстрый старт
1. Клонирование и подготовка окружения
bash
git clone <url-репозитория>
cd trading-bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
2. Настройка конфигурации
Скопируйте файл .env.example в .env и укажите свои ключи:

text
BYBIT_API_KEY=ваш_ключ
BYBIT_SECRET_KEY=ваш_секрет
CMC_API_KEY=ваш_ключ_coinmarketcap   # опционально
При необходимости отредактируйте параметры в config.py (размер позиции, TP/SL, таймфреймы и т.д.).

3. Запуск RabbitMQ и Redis
bash
cd docker
sudo docker-compose up -d
Проверьте, что контейнеры запущены: sudo docker ps.

4. Загрузка исторических данных (опционально, для обучения RL)
bash
python download_all_coins_inc_v2.py 5m 3
Эта команда загрузит 5‑минутные свечи за последние 3 года для 50+ монет. Можно также указать другой таймфрейм, например 1m.

5. Запуск vLLM сервера с моделью Llama‑3‑70B
Если вы планируете использовать LLM-агентов, убедитесь, что модель скачана в /mnt/ssd_combined/models/llama-3.3-70b-awq. Затем запустите сервер:

bash
export VLLM_SWAP_SPACE=0
python -m vllm.entrypoints.openai.api_server \
    --model /mnt/ssd_combined/models/llama-3.3-70b-awq \
    --tensor-parallel-size 4 \
    --gpu-memory-utilization 0.7 \
    --max-model-len 4096 \
    --swap-space 0 \
    --port 8000
Оставьте этот терминал открытым – сервер должен работать постоянно.

6. Запуск воркеров
Откройте 6 новых терминалов (или используйте tmux) и в каждом выполните:

bash
cd /path/to/trading-bot
source venv/bin/activate
Затем по очереди:

Technical Analyst (GPU 0)

bash
python worker_technical.py
Sentiment Analyst (GPU 1)

bash
python worker_sentiment.py
Risk Manager (GPU 2)

bash
python worker_risk.py
RL Master (GPU 3)

bash
python worker_rl.py
Triangle Scanner (CPU)

bash
python worker_triangle.py
Retest Scanner (CPU)

bash
python worker_retest.py
7. Запуск основного бота
В отдельном терминале:

bash
cd /path/to/trading-bot
source venv/bin/activate
python master_bot.py
Бот начнёт сканировать рынок, отправлять задачи воркерам и, при появлении сигналов, открывать сделки.

📊 Мониторинг
Логи воркеров и бота выводятся в консоль (цветные) и сохраняются в папку logs/ в формате JSON (с ротацией по размеру 500 МБ). В них присутствует correlation_id, позволяющий отследить всю цепочку обработки одного запроса.

RabbitMQ Web‑интерфейс: http://localhost:15672 (логин/пароль guest/guest). Здесь можно увидеть очереди, количество задач и т.д.

Redis: можно просматривать через redis-cli.

GPU: установите nvtop (sudo apt install nvtop) и запустите для мониторинга температур и загрузки.

Telegram‑уведомления (если настроены) будут приходить при критических событиях.

🧠 Как бот учится и адаптируется
Сбор опыта – каждая сделка сохраняется в trading_memory.db вместе с состоянием рынка перед входом (observation).

Обновление RL‑агента – раз в сутки запускается periodic_training(), который дообучает модель PPO на новых данных (используется rl_train_online.py).

Адаптация весов агентов – после каждой сделки веса немного корректируются (update_weights_from_performance). Более точный пересчёт по метрикам (win rate, профит‑фактор) можно добавить отдельно.

Макро‑данные – при наличии ключа CoinMarketCap бот получает реальные показатели (доминирование BTC, индекс страха и жадности) и передаёт их в промпты LLM-агентов, что повышает качество решений.

🧩 Расширение и доработка
Проект спроектирован модульно, его легко расширять:

Добавление нового агента – создайте класс, наследующий RemoteAgent в ai_agents.py, определите свою очередь и напишите соответствующего воркера. Добавьте его в список agents в оркестраторе.

Подключение второго рига – запустите дополнительные воркеры на другой машине, указав в переменной RABBITMQ_URL IP основного сервера.

Новые источники данных (order book, on‑chain) – создайте отдельного воркера, который будет периодически публиковать сигналы в свою очередь.

Обучение RL‑агента с нуля – используйте rl_train.py с нужным датасетом.

Fine‑tuning LLM – можно дообучать модель Llama на собственном корпусе торговых рассуждений (требует дополнительных инструментов, например, unsloth).
